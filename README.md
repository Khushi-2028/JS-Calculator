# JS applied Scientific Calculator

A modern and responsive **Scientific Calculator** built using **HTML, CSS, and JavaScript**. The application provides both basic and advanced mathematical operations with a sleek glassmorphism-inspired interface, customizable themes, dark/light mode support, and a mathematical formula wallpaper background.

---

## Features

### Basic Calculator Functions

* Addition (+)
* Subtraction (-)
* Multiplication (×)
* Division (÷)
* Percentage (%)
* Decimal calculations
* Clear (C)
* Backspace (⌫)

### Scientific Functions

* Square Root (√)
* Cube Root (∛)
* Power (xʸ)
* Square (x²)
* Cube (x³)
* Logarithm (log₁₀)
* Natural Logarithm (ln)
* Factorial (n!)
* Pi Constant (π)
* Parentheses Support (() )

### User Interface Features

* Light Mode / Dark Mode Toggle
* Scientific Mode Toggle
* Multiple Theme Colors
* Glassmorphism UI Design
* Responsive Layout
* Mathematical Formula Background
* Keyboard Shortcuts Support
